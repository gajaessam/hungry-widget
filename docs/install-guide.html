급식알리미 설치 안내

내가 고른 캐릭터가 말풍선으로 오늘 급식을 알려주는 Windows 위젯이에요.

설치하기

  1. 이 폴더의 geupsik-alimi-setup-버전.exe를 더블클릭해요. zip 안에서 바로 누르지 말고, 압축을 먼저 풀어 주세요.
  2. 파란색 Windows의 PC 보호 창이 뜨면 추가 정보를 누른 뒤 실행을 눌러요.

    개인이 만든 무료 앱이라 코드 서명 인증서가 없어서 뜨는 안내예요. 앱은 개인정보를 수집하지 않아요.

  3. 설치가 끝나면 설정 창이 열려요. 학교를 검색해 고르고 학년을 선택하면 바로 급식이 나와요.

캐릭터 이미지, 말투, 알레르기, 크기는 설정에서 바꿀 수 있어요. 자세한 내용은 캐릭터 우클릭 → 사용 설명서에서 볼 수 있어요.

꼭 알아 두세요

  • Windows 전용이에요. Mac과 휴대폰에서는 사용할 수 없어요.
  • 한 번 설치하면 업데이트는 자동이에요. 새 버전이 오면 말풍선으로 알려줘요.
  • 캐릭터 이미지는 PC 안에만 저장돼요. 개인적으로 사용할 수 있는 이미지만 넣어 주세요.
  • 알레르기 경고는 학교가 올린 정보를 기준으로 해요. 심한 알레르기가 있다면 영양 선생님께 꼭 확인해 주세요.
